# Guessing Game Collection

This repository contains a collection of classic text-based games implemented in Python.

## Games Included

*   **Guess the Number:** Guess a randomly generated number within a certain range.
*   **Roll the Dice:** A simple dice rolling game.
*   **Hangman:** Guess a secret word before you run out of attempts.
*   **Mastermind:** A code-breaking game where you must guess a secret 4-digit code.
*   **Minesweeper:** A simplified version of the classic minesweeper game.
*   **Rock, Paper, Scissors:** The classic hand game.
*   **Battleship:** A simplified, single-player version of the classic board game.

## How to Play

1.  Make sure you have Python 3 installed.
2.  Clone this repository.
3.  Run the `game.py` file from your terminal:

    ```bash
    python game.py
    ```

4.  A menu will appear, allowing you to choose which game you want to play.
